01 · Por qué existe

Telegram empezó a cobrar por el Bot API cloud

En agosto de 2026 Telegram comenzó a vender «peticiones» del Bot API cloud desde BotFather. El efecto en producción se pareció más a una avería que a un cambio de precio: tokens que dejaban de responder, timeouts sin causa en la red, errores que no venían de ningún sitio.

Fabella nació como apaño de un fin de semana: si el Bot API cloud se pone caro o caprichoso, hablamos con Telegram como habla la app del móvil — con una cuenta real — y volvemos a exponer el protocolo cómodo en local. Lo que ya funcionaba, sigue funcionando; solo cambia a quién le preguntas.

⚠

Sin adornos: automatizar una cuenta de Telegram (un userbot) es zona gris de sus términos de servicio y puede costar una limitación o un ban. Fabella es un experimento honesto, no una promesa de seguridad. Léelo entero antes de decidir — abajo te contamos también lo que no hace.

02 · La guía

¿BotFather o cuenta real?

Los dos caminos son legítimos, pero para cosas distintas. La pregunta no es cuál es mejor: es qué está haciendo tu bot y para quién.

Bot de BotFather · nube

El bot de toda la vida

Un bot nuevo, oficial, con su propio nombre y su token.
  • ✓Para bots públicos: tus usuarios, tus grupos, tus clientes.
  • ✓El bot no es nadie: sin riesgo para cuentas.
  • ✓El camino oficial, documentado y estable.
  • ✕Paga por petición desde ago-2026: BotFather vende el tráfico.
  • ✕Límites y throttling fuera de tu control.
  • ✕No puede escribirte primero (salvo excepciones).
Cuenta real · local

Tu cuenta de siempre + Fabella

Tu cuenta, tu máquina, el mismo protocolo familiar.
  • ✓El mismo código Bot API, sin tocarlo: cambia solo la base_url a localhost.
  • ✓Cero coste por petición: hablas como habla la app.
  • ✓Corre en tu máquina: nada pasa por servidores de terceros.
  • ✓Tu cuenta puede escribir primero y estar en cualquier chat donde ya esté.
  • ✕Zona gris del ToS: automatizar tu cuenta tiene riesgo de limitación.
  • ✕No es para bots públicos de terceros: es para lo tuyo.
  • ✕Todavía no cubre el 100% del Bot API (media y teclados, en roadmap).

03 · Bajo el capó

Cómo funciona (en serio)

Tu código cree que habla con un Bot API oficial. Delante tiene un puente local de 630 líneas legibles.

Tu código — python-telegram-bot · Hermes · curl
│ Bot API (getUpdates · sendMessage · getMe…)
▼
Fabella — 127.0.0.1:8086 ← tu máquina
│ MTProto (Telethon · long-polling)
▼
Telegram ⇄ tu cuenta real

Compatible sin tocar código: cualquier framework del Bot API funciona apuntando su servidor a http://localhost:8086. El token da igual — el puente no lo valida; el tuyo no sale de casa.

Sin webhooks y sin nube propia: solo long-polling, una consola web opcional para chatear desde el navegador, y un watchdog que relanza el puente si se cae (silencioso cuando todo va bien).

04 · Empezar

De cero a bot en tu cuenta, en 5 minutos

Necesitas Python 3.10+, una cuenta de Telegram y tu propio api_id/api_hash (gratis en my.telegram.org, 1 minuto).

terminal — bash 
$ git clone https://github.com/GonzaloMonzonC/cadencesfabella
$ cd cadencesfabella
$ pip install telethon
$ cp .env.example .env        # pon tu api_id/api_hash (my.telegram.org)
$ python scripts/login_userbot.py send +34XXXXXXXXX
$ python scripts/login_userbot.py sign +34XXXXXXXXX 12345
$ python scripts/bridge_mtproto.py
[fabella] ✅ CadencesFaBela connected as <tu nombre> (id …)
[fabella] Local Bot API  → http://localhost:8086
~5 min de setup Python 3.10+ 1 dependencia corre en tu máquina
⚠

Usa TU api_id/api_hash (my.telegram.org). No reutilices las credenciales de clientes oficiales que circulan por tutoriales: es motivo de ban y el README te avisa igual. La guía completa paso a paso vive en el repo, junto con los tropiezos reales contados en el CHANGELOG.

05 · Sin letra pequeña

Qué es y qué no es

✓ Es

  • ✓Un puente local Bot API ⇄ Telegram por MTProto. MIT, sin servicios de terceros.
  • ✓Compatible con cualquier framework del Bot API apuntado a localhost.
  • ✓Pensado para tu propia cuenta y tu propia máquina.
  • ✓Código abierto de verdad: lo lees entero en una tarde y lo auditas tú.

✕ No es

  • ✕No está afiliado a Telegram ni lo bendice nadie.
  • ✕No elimina el riesgo del ToS: automatizar tu cuenta puede costarte un límite o un ban.
  • ✕No es un Bot API completo (todavía): texto y flujos base; media y teclados en roadmap.
  • ✕No es infraestructura para bots de terceros ni para spam.
